4. NOMENCLATURA
======================================================================

4.1 Idioma: código, identificadores e comentários em INGLÊS.
    Texto visível ao usuário final do estúdio: pt-BR, só em src/studio/strings.js.
    Mensagens de erro do núcleo (ParaJacaError.message): inglês.
4.2 Arquivos e pastas: kebab-case (image-source.js, quality-panel.js).
4.3 Funções e variáveis: camelCase. Constantes de módulo: UPPER_SNAKE_CASE.
    Classes: PascalCase (única classe permitida: ParaJacaError).
4.4 Fábricas: objetos com estado são criados por funções `createXxx(...)`
    que retornam um objeto literal com métodos. NÃO use `class` (exceto o erro).
4.5 Funções puras de cálculo: verbo `compute`, `resolve`, `estimate`, `clamp`,
    `is`, `has`. Ex.: computeSigmaRef, resolveDepths, estimateLayerBytes.
4.6 Booleanos internos: prefixo is/has/should (isPaused, hasMask).
    Exceção: campos do formato da cena mantêm o nome do contrato (axisY, drift,
    opaque).
4.7 Eventos do player: strings em kebab-case exatamente:
    'ready', 'error', 'quality-change', 'focus-change'.
4.8 SUFIXOS DE UNIDADE (OBRIGATÓRIOS em toda variável/campo numérico com unidade):
    ...Css     px CSS                          (pointerXCss, widthCss)
    ...Comp    px da composição (autoria)      (contentRectComp, paddingComp)
    ...Render  px de render (canvas)           (offsetXRender, sigmaRender)
    ...Tex     texels                          (sigmaTex, paddingTex)
    ...Ref     px de referência (altura 1080)  (sigmaRef, intensityRef)
    ...Ms      milissegundos                   (frameMs)
    ...Sec     segundos                        (dtSec)
    ...Bytes   bytes                           (budgetBytes)
    Sem sufixo: valores adimensionais (depth 0–100, focus 0–100, input −1..1,
    renderScale, zoom, lod, opacity, aperture N).
    Exceção: campos do formato da cena (seção 7) mantêm os nomes do contrato
    (ex.: maxBlur é Ref, intensity é Ref, placement é Comp), documentados no JSDoc.
4.9 Conversões entre unidades DEVEM aparecer por escrito numa linha própria:
      const sigmaRender = sigmaRef * refFactor;
    NUNCA misture unidades numa mesma expressão sem conversão explícita.

8. ERROS
======================================================================

8.1 src/core/errors.js exporta exatamente:
    export const ERROR_CODES = Object.freeze({
      WEBGL_UNAVAILABLE: 'webgl-unavailable',
      CONTEXT_LOST_UNRECOVERABLE: 'context-lost-unrecoverable',
      INVALID_SCENE: 'invalid-scene',
      UNSUPPORTED_FORMAT_VERSION: 'unsupported-format-version',
      ASSET_LOAD_FAILED: 'asset-load-failed',
      TEXTURE_TOO_LARGE: 'texture-too-large',
      MEMORY_BUDGET_EXCEEDED: 'memory-budget-exceeded',
    });
    /** @typedef {typeof ERROR_CODES[keyof typeof ERROR_CODES]} ErrorCode */
    export class ParaJacaError extends Error {
      /** @param {ErrorCode} code @param {string} message
          @param {{ assetId?: string, cause?: unknown }} [details] */
      constructor(code, message, details = {}) {
        super(message, { cause: details.cause });
        this.name = 'ParaJacaError';
        this.code = code;
        this.assetId = details.assetId ?? null;
      }
    }
    export function isAbortError(error) → boolean  // error.name === 'AbortError'

8.2 Regras:
    - NUNCA engolir erro (catch vazio é proibido).
    - Cancelamento (AbortError) não é erro: é ignorado silenciosamente SÓ quando
      isAbortError(error) for true.
    - Todo erro que chega à API do player vira evento 'error' { code, message }
      (+ assetId quando houver). Erros não-ParaJacaError viram code
      'invalid-scene' se vierem da validação; nos demais casos são relançados
      via queueMicrotask(() => { throw error; }) para aparecerem no console.
    - Erro fatal: o player mostra o poster (se houver), para o loop e continua
      aceitando chamadas da API sem lançar exceção.
    - Exceção dentro de handler de evento do usuário: capturada pelo emissor e
      relançada com queueMicrotask; o loop continua.
    - Falha de compilação/link de shader: ParaJacaError('webgl-unavailable',
      `Shader <nome> failed: <log do driver>`).

9. ASSINCRONIA, CANCELAMENTO E GERAÇÃO
======================================================================

9.1 Toda função assíncrona de carga recebe `signal: AbortSignal` como último

9.2 Padrão de geração (OBRIGATÓRIO em player.js para load, setVariant,

      const generation = ++state.generation;
      state.abortController?.abort();
      const controller = new AbortController();
      state.abortController = controller;
      ... const result = await something(controller.signal);
      if (generation !== state.generation) return;   // stale result: discard
    Um resultado antigo NUNCA substitui uma escolha mais recente.
9.3 Recurso criado por uma operação descartada DEVE ser liberado
    (ImageBitmap.close(), renderer.releaseLayer).
9.4 Carga SEQUENCIAL, camada a camada (for...of com await). Sem Promise.all
    para camadas.

10. ESTADO E COMANDOS
======================================================================

10.1 Separação obrigatória dentro do player:
     - `config`: cópia da Scene (cloneScene) + variantId atual. Persistível.
     - `runtime`: tudo o mais (recursos, input suavizado, foco atual, medições,
       preset efetivo, renderScale efetivo, flags). NUNCA serializado.
10.2 Flags de atualização (bits) definidas em player.js:
     const DIRTY_FRAME = 1;          // only uniforms / frame values
     const DIRTY_LAYOUT = 2;         // viewport, framing, margins
     const DIRTY_REQUIREMENTS = 4;   // recompute requirements(), maybe rebuild
     const DIRTY_ORDER = 8;          // draw order / resolved depths
     Comandos e eventos fazem `state.dirty |= FLAG` e chamam requestFrame().
     O quadro processa e zera as flags. NUNCA comparar o modelo profundamente
     a cada quadro.
10.3 Tabela comando → flags:
     setFocus                    → DIRTY_FRAME
     pointer/teclado/roda        → DIRTY_FRAME
     setQuality (só renderScale) → DIRTY_LAYOUT
     setQuality (teto textura)   → DIRTY_LAYOUT | DIRTY_REQUIREMENTS
     resize                      → DIRTY_LAYOUT | DIRTY_REQUIREMENTS (requirements
                                   com debounce de RESIZE_REBUILD_DEBOUNCE_MS = 250)
     edit optics/motion          → DIRTY_FRAME | DIRTY_LAYOUT | DIRTY_REQUIREMENTS
     edit layer depth/order      → DIRTY_ORDER | DIRTY_LAYOUT | DIRTY_REQUIREMENTS
     edit pointOfInterest        → DIRTY_LAYOUT
     setVariant / troca de asset → reconstrução controlada (seção 15)

======================================================================
11. CAMINHO QUENTE (LOOP DE QUADROS)
======================================================================

11.1 "Caminho quente" = tudo chamado a partir do callback de requestAnimationFrame
     (cálculo de quadro + renderer.draw).
11.2 PROIBIDO no caminho quente:
     - criar objetos, arrays, closures, strings ou template strings;
     - spread, destructuring de objeto novo, Array.map/filter/forEach/reduce,
       for...of sobre Map (usar arrays pré-ordenados e for com índice);
     - gl.getError, gl.readPixels, gl.getParameter, gl.getUniformLocation,
       gl.checkFramebufferStatus, qualquer leitura síncrona da GPU;
     - await, Promise.
     Exceção 1: no modo diagnóstico (options.diagnostics definido) o renderer PODE
     chamar gl.getError após draw.
     Exceção 2: o tratamento das flags DIRTY_ORDER, DIRTY_LAYOUT e
     DIRTY_REQUIREMENTS PODE alocar, pois só ocorre depois de comandos, nunca em
     todo quadro. DIRTY_FRAME NUNCA aloca.
11.3 OBRIGATÓRIO no caminho quente:
     - arrays tipados pré-alocados com capacidade MAX_LAYERS (Float32Array,
       Uint8Array) e reutilizados;
     - uniform locations obtidas UMA vez na criação do programa e guardadas;
     - um único objeto FrameState reutilizado.
11.4 O objeto de amostra de diagnóstico é único e reutilizado; o consumidor
     (estúdio/demo) DEVE copiar os valores que quiser guardar.

12.11 Enquadramento e margem — src/core/framing.js (pura)
     export const FRAMING_MAX_ZOOM = 1.25;   // calibrate
     /**
      * @typedef {Object} FrameLayout
      * @property {number} renderPxPerCompPx  final scale (cover × framing)
      * @property {number} cameraXComp        composition point at canvas center
      * @property {number} cameraYComp
      * @property {number} marginXComp
      * @property {number} marginYComp
      * @property {number} offsetLimitXRef    max |offset| for edge layers (Infinity = no limit)
      * @property {number} offsetLimitYRef
      * @property {boolean} isMarginInsufficient
      */
     computeFrameLayout({ reference, pointOfInterest, canvasWidthRender,
       canvasHeightRender, edgeLayers }) → FrameLayout
     edgeLayers: Array<{ maxOffsetXRef: number, maxOffsetYRef: number }> para cada
     camada cujo conteúdo toca a borda da composição.
     Algoritmo (exato):
       1. refToComp = reference.height / REFERENCE_HEIGHT (1080; duplicar a
          constante localmente como REFERENCE_HEIGHT = 1080, pois framing.js não
          importa optics.js).
       2. needXComp = max(maxOffsetXRef) × refToComp; needYComp idem (0 se vazio).
       3. limitXComp = reference.width  × (1 − 1 / FRAMING_MAX_ZOOM) / 2;
          limitYComp = reference.height × (1 − 1 / FRAMING_MAX_ZOOM) / 2.
       4. marginXComp = min(needXComp, limitXComp); idem Y.
          isMarginInsufficient = needXComp > limitXComp || needYComp > limitYComp.
          offsetLimitXRef = needXComp > limitXComp ? limitXComp / refToComp : Infinity.
       5. visibleW = reference.width − 2 × marginXComp; visibleH idem.
       6. renderPxPerCompPx = max(canvasWidthRender / visibleW,
                                   canvasHeightRender / visibleH)      // cover
       7. halfViewW = canvasWidthRender / (2 × renderPxPerCompPx); halfViewH idem.
       8. cameraXComp = clamp(pointOfInterest.x × reference.width,
                              marginXComp + halfViewW,
                              reference.width − marginXComp − halfViewW); idem Y.
     maxOffset de uma camada (Ref), feito no player:
       anchor 'infinity': intensity × |100 − d| / 100
       anchor 'focus':    intensity × max(|fMin − d|, |fMax − d|) / 100
       Y = 0 se !axisY. A respiração (zoom >= 1) não exige margem.
     "Teto de intensidade" = motion.intensity da variante (com movimento reduzido
     NÃO reduzir aqui, para o enquadramento não mudar).

12.12 Transformação de uma camada para o quadro (player, caminho quente):
     zoom = computeBreathingZoom(focusCurrent, optics.breathing)
     s = layout.renderPxPerCompPx × zoom
     rectComp = retângulo do quad COM padding, em px da composição, calculado
     UMA vez quando o recurso é preparado (não por quadro):
       texPerCompX = req.contentSizeTex.width  / contentRectComp.width
       texPerCompY = req.contentSizeTex.height / contentRectComp.height
       rectComp.x = contentRectComp.x − req.paddingTex.left / texPerCompX
       rectComp.y = contentRectComp.y − req.paddingTex.top  / texPerCompY
       rectComp.width  = req.textureSize.width  / texPerCompX
       rectComp.height = req.textureSize.height / texPerCompY
     contentRectComp de uma camada = recorte do asset mapeado pelo placement:
       compX = placement.x + assetX × placement.width / asset.width (idem Y).
     Camada de borda: deslocamento limitado a ±layout.offsetLimitXRef/YRef
     (antes de converter para Render).
     xRender = (rectComp.x − cameraXComp) × s + canvasWidthRender / 2 + offsetXRender
     yRender = (rectComp.y − cameraYComp) × s + canvasHeightRender / 2 + offsetYRender
     wRender = rectComp.width × s;  hRender = rectComp.height × s
     Origem (0,0) = canto SUPERIOR esquerdo do canvas; y cresce para baixo.

13.2 src/core/quality/requirements.js (pura)
     export const PADDING_SIGMA_FACTOR = 3;          // calibrate
     export const PADDING_RECON_TEX = 2;             // calibrate
     export const LOD_RESERVE_LEVELS = 1;            // calibrate
     /**
      * @typedef {Object} LayerRequirements
      * @property {number} texScale        texels per Comp px
      * @property {Size}   contentSizeTex  content (no padding) in texels
      * @property {{left:number, top:number, right:number, bottom:number}} paddingTex
      * @property {Size}   textureSize     content + padding, in texels
      * @property {number} levels          mip levels to allocate (>= 1)
      * @property {number} maxLod          = levels − 1
      * @property {number} sigmaMaxRef     largest sigmaRef this layer can need
      */
     computeRequirements({ layer, resolvedDepth, asset, contentRectComp,
       croppedSides, variant, reference, renderPxPerCompPxAtScale1, preset,
       maxTextureSize }) → LayerRequirements
     Algoritmo (exato):
       1. sigmaMaxRef:
          'sharp' → 0; 'fixed' → min(fixedBlur, maxBlur);
          'dynamic' → computeSigmaRef no pior foco dentro de focusRange:
            excessMax = max(0, max(|d − fMin|, |d − fMax|) − tolerance)
            sigmaMaxRef = min(maxBlur, excessMax × kAperture)
       2. texScale = min(
            renderPxPerCompPxAtScale1 × (1 + optics.breathing),   // display need
            asset.width / layer.placement.width,                   // never above original
            preset.textureMaxHeight / reference.height)            // preset ceiling
       3. sigmaMaxTex = sigmaMaxRef × (reference.height / 1080) × texScale
          padOne = sigmaMaxRef > 0 ? ceil(PADDING_SIGMA_FACTOR × sigmaMaxTex + PADDING_RECON_TEX) : 0
          paddingTex lado L/T/R/B = croppedSides.<lado> ? padOne : 0
          (lado que toca a borda da composição: padding 0 e CLAMP_TO_EDGE)
       4. contentSizeTex = { width: max(1, round(contentRectComp.width × texScale)),
                             height: max(1, round(contentRectComp.height × texScale)) }
          textureSize = content + paddings.
       5. Se textureSize.width ou height > maxTextureSize: reduzir texScale
          proporcionalmente (texScale ×= maxTextureSize / maior lado), refazer 3–4
          (no máximo 3 iterações). Se ainda exceder: lançar NÃO; devolver e o
          chamador emite 'texture-too-large'.
       6. lodBlurMax = 0.5 × log2(3 × sigmaMaxTex² + 1)
          fullChain = floor(log2(max(textureSize.width, textureSize.height))) + 1
          levels = min(fullChain, ceil(max(lodBlurMax, 1)) + 1 + LOD_RESERVE_LEVELS)
          ('sharp' também tem mipmaps: levels >= 2 quando fullChain >= 2.)
     satisfiesRequirements(current, needed) → boolean
       = current.texScale >= needed.texScale × (1 − 1e-6)
         && current.sigmaMaxRef >= needed.sigmaMaxRef − 1e-6
         && current.levels >= needed.levels
     Entradas que disparam recomputação: maxBlur, aperture, tolerance, focusRange,
     depth, focusMode, fixedBlur, anchor, axisY, viewport, proporção, preset.

14.5 pyramid.js — buildPyramid(gl, programs, texture, textureSize, levels)
     Para k = 1 .. levels−1:
       srcW = max(1, floor(w0 / 2^(k−1))) ... (use o loop: w_k = max(1, floor(w_{k−1}/2)))
       1) temp = textura RGBA8, 1 nível, tamanho (w_k, h_{k−1}),
          MIN/MAG = LINEAR, CLAMP_TO_EDGE.
       2) Passe H: framebuffer → temp; amostra `texture` com u_srcLod = k−1,
          u_srcSize = (w_{k−1}, h_{k−1}), u_dstSize = (w_k, h_{k−1}), u_dir = (1, 0).
       3) Passe V: framebuffer → `texture` nível k (framebufferTexture2D com level k);
          amostra temp com u_srcLod = 0, u_srcSize = (w_k, h_{k−1}),
          u_dstSize = (w_k, h_k), u_dir = (0, 1). Neste passe `texture` NÃO está
          ligada a nenhuma unidade de textura (só temp).
       4) gl.deleteTexture(temp).
     Ao final: deletar o framebuffer; restaurar viewport e framebuffer null;
     gl.disable(BLEND) durante os passes.
     NUNCA ler e gravar a mesma textura no mesmo passe.
     Fragment da pirâmide (exato; filtro 1-4-6-4-1/16 avaliado no centro do par
     de texels com amostragem linear = núcleo efetivo 1-5-10-10-5-1/32, centrado,
     sem deslocamento entre níveis):
       uniform sampler2D u_src; uniform float u_srcLod;
       uniform vec2 u_srcSize; uniform vec2 u_dstSize; uniform vec2 u_dir;
       void main() {
         vec2 center = gl_FragCoord.xy * (u_srcSize / u_dstSize);  // in src texels
         vec4 sum = vec4(0.0);
         sum += textureLod(u_src, (center - 2.0 * u_dir) / u_srcSize, u_srcLod) * 1.0;
         sum += textureLod(u_src, (center - 1.0 * u_dir) / u_srcSize, u_srcLod) * 4.0;
         sum += textureLod(u_src, center / u_srcSize, u_srcLod) * 6.0;
         sum += textureLod(u_src, (center + 1.0 * u_dir) / u_srcSize, u_srcLod) * 4.0;
         sum += textureLod(u_src, (center + 2.0 * u_dir) / u_srcSize, u_srcLod) * 1.0;
         outColor = sum / 16.0;
       }
     Vertex da pirâmide: quad em tela cheia (a_corner → gl_Position = a_corner*2−1).
     Observação: gl_FragCoord usa linhas de memória do framebuffer; a amostragem
     usa as mesmas linhas de memória, então a orientação se preserva sem flip.

16.4 Loop:
     - requestFrame() agenda um rAF só se nenhum estiver agendado e o player não
       estiver pausado.
     - dt = clampDt((timestamp − lastTimestamp) / 1000).
     - Roda enquanto houver: input não convergido, foco não convergido, deriva
       ativa, ou flags sujas. Para na convergência.
     - Pausa: document.visibilityState === 'hidden' (visibilitychange) e
       IntersectionObserver (cena fora da tela). Ao voltar: lastTimestamp = null
       (o primeiro dt após pausa é 0).
     - fpsTarget 30: desenha só se (timestamp − lastDraw) >= 1000/30 − 4 ms.
       'free' e 60: desenha em todo rAF.
16.5 Entrada (desktop):
     - pointermove no canvas: inputTarget = clamp(((x − centroX)/(larguraCss/2)),
       −1, 1) por eixo; pointerleave: alvo 0.
     - Alt + wheel: foco ± WHEEL_FOCUS_STEP = 2 por evento (deltaY > 0 → +);
       preventDefault SÓ quando Alt estiver pressionado e o foco for tratado.
     - Teclado (canvas com foco): ArrowRight/ArrowUp → foco +KEY_FOCUS_STEP (5);
       ArrowLeft/ArrowDown → −5; preventDefault só nessas teclas.
     - Clique → foco por silhueta (fase B): camada mais à frente (exceto 'sharp')
       cuja máscara contém o ponto, com CLICK_TOLERANCE_CSS = 6 (calibrate),
       usando a transformação completa da camada (offset + zoom + enquadramento).
     - setFocus(d) limita d a focusRange. animate false → atual = alvo.
     - prefers-reduced-motion lido via matchMedia e escutado (change).
16.6 Erros fatais: mostrar poster (se houver posterAssetId), parar loop,
     manter API respondendo (métodos viram no-op seguros).
