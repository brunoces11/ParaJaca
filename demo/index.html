Importar imagens e animações

Arraste as imagens para esta janela ou use “Selecionar imagens”. Arquivos terminados em _1 … _7 vão para a camada correspondente (1 = fundo); os demais entram nas camadas livres, na ordem do nome. Camadas sem arquivo novo mantêm a atual. Aceita PNG, JPG, WebP, SVG, Lottie JSON e .lottie. Use “Código SVG” na camada para colar o SVG. Animações Lottie iniciam em loop; scripts e expressões não são executados. Cada imagem mantém suas dimensões originais, maior ou menor que 1920×1080; ajuste o alinhamento em X/Y.

Inserir código SVG

Cole o documento SVG completo. O tamanho usa width/height; na ausência, usa o viewBox. Animações SMIL compatíveis são reproduzidas; scripts não são executados.
